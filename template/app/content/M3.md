## Media figures

The `media` block renders a captioned figure. `src:` is relative to the `app/` folder;
the convention is `content/media/`.

```media
type: image
src: content/media/placeholder.png
caption: An image figure — drop your own files into content/media/.
```

Self-hosted video plays with native controls, no external service:

```media
type: video
src: content/media/demo.mp4
caption: A tiny self-hosted mp4 that ships with the template.
```

YouTube embeds use a **click-to-load facade** — the player only loads when the
learner clicks play (faster pages, no tracking before consent, hermetic tests):

```media
type: youtube
youtube: aqz-KE-bpKQ
caption: Replace the ID with any YouTube video ID.
```

## LaTeX math

Inline math like $e^{i\pi} + 1 = 0$ and display equations both render via KaTeX,
protected from markdown mangling (the renderer extracts them before parsing):

$$\hat{y}_{t+1} = \alpha\, y_t + (1-\alpha)\, \hat{y}_t$$

$$\text{MSE} = \frac{1}{n}\sum_{t=1}^{n} (y_t - \hat{y}_t)^2$$
