## Everything here is plain markdown

Write **bold**, *italic*, `inline code`, [links](https://example.com), blockquotes:

> A blockquote with a key insight — styled with your theme's accent border.

Lists render with accent markers:

- First point
- Second point
- Third point

Tables work too:

| Block type | Renders as | Notes |
|---|---|---|
| `python` + `anno` | annotated code window | see Module 2 |
| `interactive` | mounted component | chartlab, or your own labs |
| `quiz` | checkpoint card | first attempt counts |
| `media` | figure with caption | see Module 3 |

## Checkpoint

Quizzes are one fenced block each. The answer index is **0-based**.

```quiz
id: m1-1
objectives:
  - obj-m1-manifest
q: How do you add a new module to the course?
opts:
  - write a new M<n>.md file in content/ and register it in shell.js MODULES
  - edit index.html and add a new page
  - restart a server
answer: 0
expl: One markdown file plus one line in the MODULES array (order = sidebar order). index.html never changes per module.
```

```quiz
id: m1-2
objectives:
  - obj-m1-first-attempt
q: What happens if a quiz is answered wrong on the first attempt?
opts:
  - nothing is recorded — try again
  - the wrong score is recorded permanently — first attempt only
  - the course locks
answer: 1
expl: First-attempt scoring: the first Check click writes the score; retries give feedback but never overwrite it.
```
