# Portable Skill Stage And Release Checklist

Status as of 2026-09-14.

## Stage 1 — Stabilize Current Structure: Complete

- Keep `/Users/jensu/.codex/skills/course-factory` installed and unchanged.
- Keep `skills/course-factory-portable` as the portable package.
- Keep `template/` as the only canonical runtime.
- The former `renderer.js` indentation drift is fixed.
- Canonical drift is detected by:

  ```bash
  node skills/course-factory-portable/scripts/package.js --check
  ```

## Stage 2 — Deterministic Portability: Complete

- Packaging is generated by:

  ```bash
  node skills/course-factory-portable/scripts/package.js
  ```

- Manual edits to `skills/course-factory-portable/framework/` are forbidden.
- The package excludes `dist/`, destination courses, `graphify-out/`, full
  notes history, `node_modules/`, OS metadata, generated reports, and stale
  generated content.
- The package records SHA-256 file checksums in
  `skills/course-factory-portable/framework/package-manifest.json`.
- The portable initializer supports opt-in dependency installation with
  `--install` and a full empty-directory canonical run with `--validate`.
- The complete local gate is:

  ```bash
  node skills/course-factory-portable/scripts/validate.js
  ```

## Stage 3 — Reduce Manual Duplication: Complete

- The embedded framework mirror is generated from canonical `template/` and
  root contracts.
- The mirror is retained because the portable skill remains self-contained.
- CI enforces canonical runtime validation, portable packaging drift/checksums,
  full temporary empty-directory initialization, and a final checksum recheck.

## Stage 4 — Publish Public Portable Release: Complete

Completed in this order:

1. Trigger a clean CI run after the latest changes.
2. Confirm the hosted CI full portable validation passes.
3. Validate the packaged skill from a fresh clone or clean-machine environment.
4. Tag `course-factory-portable-v1`.
5. Publish the tagged portable skill and checksum.
6. Install and validate the tagged skill on another machine or isolated skills
   directory using:

   ```bash
   node scripts/init.js --target /path/to/empty-repository --install --validate
   ```

7. Require this final report:

   ```text
   template/tests/generated/agent-run.json → status: "success"
   ```
