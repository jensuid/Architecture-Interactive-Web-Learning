## Code with line-by-line annotations

A `python` block (any language — it's highlighted as python by default) followed
immediately by an `anno` block whose rows are `LINE|explanation`:

```python
import pandas as pd

# load the demo dataset that ships with this template
df = pd.read_csv('demo.csv', parse_dates=['date'])
df = df.set_index('date')

print(df.head())
```

```anno
1|Import pandas under its universal alias.
4|parse_dates turns the date column into real datetimes at load time.
5|A datetime index unlocks slicing, resampling, and plotting.
```

The header makes the pedagogical stance explicit: code runs on **your machine**,
never in the browser — copy it out and run it.
